# История изменений Universal Document RAG

## v5.0.0 — универсальный корпус, таблицы, формулы, проверяемый поиск

- Убран жёсткий предметный контекст КОИБ (`RAG_DOMAIN=general` по умолчанию; `koib` — opt-in).
- XLSX/XLSM (листы, реальные номера строк/ячейки, оригинальные Excel-формулы), презентации PPTX, HTML со spanning-ячейками, JSON/JSONL, CSV/TSV, PDF, DOCX и текстовые документы.
- Текстовые структуры Office Math (OMML), raw XML исходных формул; для PDF-сканов — консервативное обнаружение и OCR прямоугольной табличной сетки.
- Двойное представление таблиц: неизменённая Markdown-сетка + факты по строкам с заголовками колонок для поиска и точной цитаты.
- Относительный путь источника предотвращает путаницу одинаково названных файлов; лист, строка, слайд и chunk_id проходят до API.
- Обновление и удаление источников в lexical-only режиме; безопасное перестроение векторов при изменениях в hybrid-mode, документированные ограничения.
- Экономичный SQLite-only профиль, Docker-профили и отдельные зависимости без Torch для масштабного первичного импорта.
- Проверка чисел и реальности цитат, привязка кэша к версии индекса, универсальные правила отказа при отсутствии доказательств.
- Новый офлайн-инструмент `tools/quality_gate.py` для измерения Recall@k / MRR@k.
- 51 автоматический тест и воспроизводимый синтетический прогон по 180 документам; точные ограничения в `QUALITY_REPORT.md`.

# Изменения KOIB RAG

## v4.13.0 — устойчивость, безопасность и проверяемость

- Сняты прежние ограничения 2 ГБ оперативной памяти.
- Восстановлена корректная структура серверной сборки и пути Docker Compose.
- Исправлена упаковка и проверка SHA-256 переносимых индексов; распаковка
  выполняется во временную директорию до переключения на новый индекс.
- Запрещена загрузка FAISS pickle без явного доверия оператором.
- BM25/SQLite работает даже без Hugging Face и других тяжёлых библиотек ML.
- Расширены контракт HTTP API и проверка входных параметров;
  API без секретного ключа закрыт по умолчанию.
- VK Callback по умолчанию отключён до заполнения credentials.
- Добавлена проверка заполненности индекса в `/ready` с HTTP 503.
- Семантический кеш и повторная генерация отключены по умолчанию;
  настроены безопасные условия повторного использования ответов.
- Добавлены автотесты, offline requirements, GitHub Actions CI и quality report.
- Исправлены замены модели `pymorphy2` на `pymorphy3` для актуальных Python.

## Обратная совместимость

- После обновления задайте `KOIB_API_KEY`.
- Для индекса FAISS установите `KOIB_TRUST_FAISS_PICKLE=true` только при
  наличии доверенного происхождения архива.
- Если раньше использовался VK Callback, обязательно заполните
  `VK_CONFIRM_CODE`, `VK_GROUP_ID` и `VK_SECRET_KEY`.
- Для восстановления старого поведения кеша установите
  `SEMANTIC_CACHE_ENABLED=true` (не рекомендуется для критичных ответов).
